# Mountain_classifier

Приложение, суть которого заключается в определении на онлайн карте гор. Карта представляет из себя вид местности сверху представленной в монохроме коричневого цвета. 
Приложение состоит из модели, обходчика карты и дискорд бота, через которого пользователь взаимодействует с приложением.
На данный момент модель имеет точность ~85% и уверенность в своих ответах ~80%
Обходчик карты находится в разработке. Бот находится в разработке.
Модель изначально обучалась с расчетом на то, что она будет определять горы, холмы и равнины. На данный момент модель работает в бинарном режиме - гора/не гора. Наработки связанные с дополнительным различением холмов и равнин оставлены в коде на случай, если потребуется реализовать такую функцию.
